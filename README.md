# Escape Room Maze Game

## Project Overview
The Escape Room Maze Game is a web-based game that combines the thrill of navigating a maze with answering trivia questions to overcome obstacles. Players control a character that must move through a 7x7 grid maze while answering questions on various topics. Correct answers allow the player to progress, while incorrect answers force them to backtrack. This game is designed to be both fun and educational, testing players' knowledge in various subjects.

## Installation
To run the Escape Room Maze Game locally, follow these steps:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/yourusername/escape-room-maze-game.git
   ```

2. **Navigate to the project directory**:
   ```bash
   cd escape-room-maze-game
   ```

3. **Open the `index.html` file in your web browser**. You can simply double-click the file or use a local server for better performance (like using `Live Server` in Visual Studio Code or similar).

## Usage
Once the game is opened in your web browser:

- Use the arrow keys (Up, Down, Left, Right) to move your character (😊) through the maze.
- When you encounter an obstacle, a trivia question will pop up.
- Answer the question correctly to advance; an incorrect answer will require you to backtrack to the previous position.

## Features
- Intuitive grid-based maze navigation using keyboard arrow keys.
- A trivia question system integrated with obstacles, enhancing the gameplay experience.
- Responsive and visually appealing design with a modern user interface.
- Questions in Spanish covering various topics, aimed at testing general knowledge.

## Dependencies
This project does not have any external dependencies and is a self-contained HTML/JavaScript application. It uses only standard web technologies (HTML, CSS, JavaScript) that are supported by all modern web browsers.
